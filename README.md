# Cab Booking System

## Description
A simple Cab Booking System developed using Python. This project demonstrates Object-Oriented Programming (OOP), classes, objects, and inheritance.

## Features
- Parent `Vehicle` class
- Child `Car` and `Bike` classes
- Stores vehicle number, brand, driver name, and price per kilometer
- Allows customers to select a vehicle
- Calculates fares based on travel distance
- Supports multiple trips

## Technologies Used
- Python
- Object-Oriented Programming (OOP)

## Project Structure
- `main.py` – Runs the application and handles bookings.
- `vehicles.py` – Contains the Vehicle, Car, and Bike classes.
- `fare.py` – Calculates the trip fare.

## How to Run
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python main.py
```

## Fare Calculation
**Total Fare = Price Per KM × Distance**

Example: ₹20 × 15 KM = ₹300
